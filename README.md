# ⚡ Algo Lab

### *See Algorithms. Understand Algorithms. Master Algorithms.*

**Algo Lab** is an interactive platform designed to make **Design & Analysis of Algorithms (DAA)** easier to learn through visual simulations, step-by-step execution, and performance comparisons.

---

## 🚀 What You Can Explore

🧩 **Visualize** — Watch algorithms execute step-by-step  
⚙️ **Understand** — Explore how each algorithm works  
📊 **Compare** — Analyze time & space complexity  
🎯 **Experiment** — Try different inputs and simulations  

---

## ⚡ Quick Start

```bash
git clone https://github.com/tanishghormare18/algo-lab.git
cd algo-lab
```

Then open **`index.html`** in your browser, or use **VS Code Live Server** for the best experience.
